# Langues

*[English](../en/i18n.md) · [Polski](../pl/i18n.md) · Français · [Deutsch](../de/i18n.md)*

Comment Squirrel! parle anglais, polonais, français et allemand, et comment changer un texte ou ajouter une langue. Le
guide pour les traducteurs (le format du fichier, pas à pas) :
[Squirrel!/translations/README.md](../../../Squirrel!/translations/README.md).

## 1. Dans le code

Chaque texte est en anglais dans le code, entouré de `_()` là où il est dessiné :

```python
from i18n import _
Lcd.drawString(_("Saved"), 5, 5)
renderer.render_options(_("Synced %d of %d") % (done, total))    # translate the pattern, then fill it in
```

- **Les données restent en anglais** dans leurs propres fichiers - les menus (`menu_tree.py`), les réglages, leur aide
  et leurs choix (`appconfig_schema.py`), les noms des blocs (`intervals.py`), les noms des jours - et sont traduites là
  où elles sont dessinées. La valeur d'un réglage dans `config.txt` ne change jamais avec la langue.
- **Un texte construit ailleurs en anglais** (les lignes d'état Bluetooth de `ble/central.py`, qui tourne sans écran)
  est traduit par son modèle : `i18n.fill(text, TEMPLATES)` trouve de quel modèle `%s` / `%d` vient le texte, traduit
  le modèle et remet les mêmes valeurs ; `fill(text, TEMPLATES, INNER)` traduit aussi les valeurs (la raison dans
  "failed: %s").
- **Pas traduits, exprès :** le texte sous l'horloge (la devise de l'appareil : *no need to go nuts*, *Squirrel! is
  watching*), les noms des langues (chacun dans sa langue, pour qu'on le trouve quelle que soit celle de l'écran), les
  lignes du journal et les commentaires de `config.txt`.
- **Remplissage :** MicroPython n'a pas `str.ljust`, et son `"%-10s"` compte les octets : un libellé avec ą ou é sort
  trop court. Les colonnes utilisent `charmap.pad(text, width)`.

## 2. À l'exécution

`lang/<code>.py` contient `T = (english, translated, english, translated, ...)` trié par texte anglais ; `_()` trouve un
texte par recherche dichotomique. Figé dans le firmware, le tuple reste en flash : une langue ne coûte presque rien en
RAM (moins de 1 Ko sur le Cardputer). Un texte sans traduction s'affiche en anglais.

- `_()` garde les 200 derniers textes cherchés (un écran redessine les mêmes) : 91 µs par texte sur la montre au lieu
  de 763 µs, le dessin environ 2 % plus lent qu'en anglais.
- La langue suit le réglage `LANGUAGE` via `cfg.on_change` ; `_()` lui-même ne lit rien.
- Toute langue autre que l'anglais active la police (`squirrel_app._language_font`). Sur le Cardputer, c'est
  `squirrel.vlw` ; la police 6 × 8 des montres a les lettres accentuées des quatre langues intégrées
  (`drivers/glcdfont_latin.py`, générée par `tools/fonts/make_latin_glyphs.py`). Les lettres qu'un écran ne sait pas
  dessiner sont simplifiées (`charmap.fold` : ą → a).
- **Tes propres textes sur l'appareil :** `<BASE_DIR>/lang_<code>.tsv` (`/Squirrel/lang_fr.tsv` - sur la carte SD du
  Cardputer), au format de `translations/<code>.tsv`, avec seulement les lignes que tu veux différentes. Ils l'emportent
  sur la table (`lang_en.tsv` change aussi les textes anglais), sont lus quand la langue est choisie, et sont les seuls
  textes gardés en RAM.

## 3. Les fichiers

```
translations/<code>.tsv     the translations: "en<TAB><code>", then "English<TAB>translation" lines (\n = line break)
translations/README.md      the guide for translators
lang/<code>.py              GENERATED from translations/<code>.tsv - frozen into the firmware
tools/i18n/build.py         translations/*.tsv -> lang/*.py
tools/i18n/check.py         every text translated? placeholders the same? labels short enough? (exit 1 if not)
tools/i18n/texts.py         where the texts are: _() calls in the code, plus the data (menus, settings, names)
tools/i18n/unwrapped.py     string literals that look like UI text but have no _() (a list to read, not to trust)
tools/i18n/wrap.py          puts _() around the texts a file draws (review the diff)
```

```bash
python3 tools/i18n/check.py              # summary
python3 tools/i18n/check.py --missing    # the missing texts, with where they are used
python3 tools/i18n/check.py --add        # add them to every translations/*.tsv, to be translated
python3 tools/i18n/build.py              # then the tables for the firmware
```

`check.py` arrête aussi une traduction dont les `%s` / `%d` diffèrent de l'anglais, et un libellé de réglage de plus de
18 caractères (Personnaliser montre un libellé et sa valeur sur une ligne).

## 4. Une nouvelle langue

1. Copie un fichier vers `translations/<code>.tsv`, change la première ligne en `en<TAB><code>`, traduis la deuxième
   colonne.
2. Ajoute le code à `LANGUAGES` dans `i18n.py`, aux choix de `LANGUAGE` dans `appconfig_schema.py`, et son propre nom à
   `_NATIVE_NAMES` dans `screens/personalize_screen.py`.
3. Les lettres qui manquent à la police des montres : ajoute-les à `LETTERS` dans `tools/fonts/make_latin_glyphs.py`
   (une lettre de base et un signe) ou dessine-les dans `DRAWN`, puis `--write` ; le `squirrel.vlw` du Cardputer a tout
   Latin-1 et Latin Extended-A.
4. `check.py`, `build.py`, une compilation ; des captures de chaque écran (`tools/sim/shots_scenario.py`, avec un
   contenu d'exemple dans la langue ajouté à ses `SAMPLES` ; `tools/hwtest/twatch_screens.py --lang <code>`) - et
   lis-les en utilisateur : chaque texte tient-il, sonne-t-il juste ?

## 5. Écrire les textes

- Court : une ligne du Cardputer a 38-40 caractères, un libellé de réglage 18 ; une ligne de la montre en taille 2 en
  a 20.
- Un mot pour une chose partout (*routine*, *tâche*, *l'écureuil* - l'appareil que les autres attendent) ; le même
  registre partout - simple, calme, jamais grondeur.
- Pas d'accord grammatical avec une valeur insérée (un nom de bloc, un nom d'appareil) : *Ensuite : %s*, pas
  *Suivant : %s*, puisque le bloc peut être *Pause* ou *Repos*.
- Des noms de jours sur deux lettres dans les sélecteurs (*Lu Ma Me*) : une seule lettre est ambiguë dans plusieurs
  langues.
