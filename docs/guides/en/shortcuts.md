# Shortcuts and navigation

*[Polski](../pl/shortcuts.md) · [Français](../fr/shortcuts.md) · [Deutsch](../de/shortcuts.md)*

How to get around Squirrel! with the Cardputer's keys and the watch's touch screen. Version 2.0.

## Everywhere

| Cardputer | Watch | What it does |
|---|---|---|
| UP / DOWN | swipe up / down | move in a list, scroll a text |
| ENTER (or RIGHT) | tap | open, choose, confirm |
| ESC (or LEFT) | swipe right, a tap on the title, the side button | back |
| G0 | — | quick voice recorder: from the clock and the menus it starts at once; G0 again saves |
| DEL three times | — | delete the note, To-Do or recording on screen (the first DEL shows a warning; ESC cancels) |

**DEL** is FN + Backspace. **CTRL, OPT, Aa, ALT, FN** are keys of their own on the clock face; elsewhere they work
as modifiers (Aa = capital letters, ALT + a letter = a Polish / German letter, see *Personalize → Keyboard → ALT+letter layout*).

## The clock face

| Cardputer | Watch | What it does |
|---|---|---|
| any other key | tap | the main menu |
| OPT | hold | start / pause the focus timer |
| **Aa** | **swipe down** | **quick sync**: the Cardputer syncs every Bluetooth device and comes back; the watch waits for the Cardputer and comes back |
| CTRL, then T | — | a new To-Do (one key after the other) |
| CTRL, then N | — | a new text note |
| **TAB** | — | **the TAB menu** (below) |

### The TAB menu (Cardputer)

A small menu over the clock. **TAB** or UP / DOWN move, ENTER opens, ESC closes; or press the letter:

| Letter | Opens |
|---|---|
| M | Mind dump — a quick thought, ENTER saves it and you are back on the clock |
| T | To-Do list |
| N | Text notes |
| V | Voice notes |
| S | Quick sync (as Aa) |

## Lists (To-Do list, Text notes, Mind dump, Voice notes)

- The first row, **+ [New item]**, creates one.
- **To-Do list:** OPT marks the highlighted To-Do done / not done; a To-Do with `>` lines opens as a checklist.
  Watch: a long press marks it done.

## Reading and writing

| Screen | Keys |
|---|---|
| Viewer (a note, a To-Do) | UP / DOWN scroll, RIGHT the next one, ENTER edit, DEL ×3 delete, ESC back. Watch: swipes scroll by a page |
| Checklist | UP / DOWN an item, OPT tick / untick, ENTER edit the list, ESC back. Watch: a tap ticks |
| Editor | FN + arrows move the cursor, ENTER a new line, Backspace / DEL delete, **CTRL+S save**, ESC discard |
| Mind dump | ENTER saves, ESC twice discards |
| Recorder | ENTER or G0 start / stop and save, ESC discards the take |
| Player | ENTER pause / play, LEFT / RIGHT 10 s back / forward, UP / DOWN volume, DEL ×3 delete, ESC stop |

## Focus tools

| Screen | Keys |
|---|---|
| Pomodoro, Training | ENTER start / pause, DEL stop, ESC leave (the timer keeps running). Training: RIGHT edits the blocks (UP / DOWN a block, LEFT / RIGHT shorter / longer, ENTER colour, DEL remove, ESC save) |
| Metronome | LEFT / RIGHT the interval, UP / DOWN volume, ENTER start / stop |
| Breathing | LEFT / RIGHT the exercise, ENTER start / stop |
| Statistics | ENTER start / pause the focus timer; LEFT / RIGHT: this device / each synced device / together |
| Routines | ENTER open / new; in a routine ENTER edits a row (time: LEFT / RIGHT hour or minutes, UP / DOWN change; days: LEFT / RIGHT a day, ENTER tick). Watch: a tap switches a routine on / off |
| A routine is due | OPT done, DEL skip; no answer for 30 s = it comes back later |

On the watch every one of these screens has its own buttons (*Start*, *Pause*, *−*, *+* ...), and a tap on the
title goes back.

## Bluetooth (Settings → Bluetooth)

| Cardputer | What it does |
|---|---|
| ENTER on *Sync now* | sync every device |
| ENTER on *Add device* | look for devices; ENTER adds the one highlighted (type the code the watch shows, then ENTER) |
| ENTER on a device | sync only that one; **DEL twice** forgets it |
| ENTER on *Auto sync* | switch the period: on demand / every 15, 30, 60, 120, 240 min |
| ESC while it works | stop |

Watch: *Settings → Bluetooth* waits for the Cardputer for 2 minutes; swipe down on the clock does the same and comes
back by itself.

## Settings

- **Personalize:** groups → settings → one setting. UP / DOWN move, ENTER opens, ESC back; **DEL** on a setting puts
  its default back. Choices (on / off, colours, options) are picked from a list. Numbers and text are typed: FN +
  LEFT / RIGHT move the cursor, FN + UP / DOWN change a number by its step. ENTER applies, ESC cancels. Watch: a tap
  switches on / off, numbers have + / − buttons, a long press puts the default back.
- **Silent mode:** the hours and days when the sound / buzzer / LED keep quiet.
- **Set time:** LEFT / RIGHT the field, UP / DOWN change it, ENTER save.
