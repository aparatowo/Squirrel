# Skróty i nawigacja

*[English](../en/shortcuts.md) · Polski · [Français](../fr/shortcuts.md) · [Deutsch](../de/shortcuts.md)*

Jak poruszać się po Squirrel! klawiszami Cardputera i ekranem dotykowym zegarka. Wersja 2.0.

## Wszędzie

| Cardputer | Zegarek | Co robi |
|---|---|---|
| UP / DOWN | przesunięcie w górę / w dół | ruch po liście, przewijanie tekstu |
| ENTER (albo RIGHT) | stuknięcie | otwórz, wybierz, potwierdź |
| ESC (albo LEFT) | przesunięcie w prawo, stuknięcie w tytuł, boczny przycisk | wstecz |
| G0 | — | szybki dyktafon: z zegara i z menu zaczyna od razu; G0 jeszcze raz zapisuje |
| trzy razy DEL | — | usuń notatkę, zadanie albo nagranie z ekranu (pierwszy DEL pokazuje ostrzeżenie; ESC anuluje) |

**DEL** to FN + Backspace. **CTRL, OPT, Aa, ALT, FN** na tarczy zegara są osobnymi klawiszami; gdzie indziej działają
jako modyfikatory (Aa = wielkie litery, ALT + litera = polska / niemiecka litera, zobacz *Personalizacja → Klawiatura
→ Układ ALT+litera*).

## Tarcza zegara

| Cardputer | Zegarek | Co robi |
|---|---|---|
| każdy inny klawisz | stuknięcie | menu główne |
| OPT | podwójne / potrójne stuknięcie | włącz / wstrzymaj licznik skupienia (zegarek: podwójne stuknięcie włącza, potrójne wstrzymuje - na zapalonym ekranie: stuknięcie w ciemny tylko go budzi) |
| **Aa** | **przesunięcie w dół** | **szybka synchronizacja**: Cardputer synchronizuje każde urządzenie Bluetooth i wraca; zegarek czeka na Cardputera i wraca |
| CTRL, potem T | — | nowe zadanie (klawisz po klawiszu) |
| CTRL, potem N | — | nowa notatka tekstowa |
| CTRL, potem J | — | dzisiejszy dziennik sukcesu (z gotową nową linią) |
| **TAB** | — | **menu TAB** (niżej) |

### Menu TAB (Cardputer)

Małe menu nad zegarem. **TAB** albo UP / DOWN przesuwają, ENTER otwiera, ESC zamyka; albo naciśnij literę:

| Litera | Otwiera |
|---|---|
| M | Mind dump — szybka myśl, ENTER ją zapisuje i wracasz na zegar |
| T | Lista To-Do |
| N | Notatki tekstowe |
| J | Dziennik sukcesu - dzisiejsza lista |
| V | Notatki głosowe |
| S | Szybka synchronizacja (jak Aa) |

## Listy (Lista To-Do, Notatki tekstowe, Mind dump, Notatki głosowe)

- Pierwszy wiersz, **+ [Nowy]**, tworzy nowy wpis.
- **Lista To-Do:** OPT oznacza zaznaczone zadanie jako zrobione / niezrobione; zadanie z liniami `>` otwiera się jako
  checklista. Zegarek: długie przytrzymanie oznacza je jako zrobione.

## Czytanie i pisanie

| Ekran | Klawisze |
|---|---|
| Podgląd (notatka, zadanie) | UP / DOWN przewijają, RIGHT następne, ENTER edycja, DEL ×3 usuń, ESC wstecz. Zegarek: przesunięcia przewijają o stronę |
| Checklista | UP / DOWN punkt, OPT odhacz / cofnij, ENTER edytuj listę, ESC wstecz. Zegarek: stuknięcie odhacza |
| Edytor | FN + strzałki przesuwają kursor, ENTER nowa linia, Backspace / DEL usuwają, **CTRL+S zapisz**, ESC odrzuć |
| Mind dump | ENTER zapisuje, ESC dwa razy odrzuca |
| Dyktafon | ENTER albo G0 start / stop i zapis, ESC odrzuca nagranie |
| Odtwarzacz | ENTER pauza / graj, LEFT / RIGHT 10 s wstecz / do przodu, UP / DOWN głośność, DEL ×3 usuń, ESC stop |

## Skup się

| Ekran | Klawisze |
|---|---|
| Pomodoro, Trening | ENTER start / pauza, DEL stop, ESC wyjście (timer liczy dalej). Trening: RIGHT edytuje bloki (UP / DOWN blok, LEFT / RIGHT krócej / dłużej, ENTER kolor, DEL usuń, ESC zapisz) |
| Klepsydra | UP / DOWN minuta więcej / mniej, LEFT / RIGHT pięć, cyfry wpisują minuty, ENTER start / pauza, DEL stop, ESC wyjście (liczy dalej). Zegarek: − / + (przytrzymaj: szybciej), Start, Pauza, Stop |
| Metronom | LEFT / RIGHT odstęp, UP / DOWN głośność, S pisk / klik, ENTER start / stop |
| Oddychanie | LEFT / RIGHT ćwiczenie, ENTER start / stop |
| Statystyki | ENTER start / pauza licznika skupienia; **-** odejmuje 15 minut (rozproszenie), DEL dwa razy zeruje dzień (zegarek: *-15*, *Zeruj* stuknięte dwa razy); LEFT / RIGHT: to urządzenie / każde zsynchronizowane / razem |
| Rutyny | ENTER otwórz / nowa; w rutynie ENTER edytuje wiersz (czas: LEFT / RIGHT godzina albo minuty, UP / DOWN zmiana; dni: LEFT / RIGHT dzień, ENTER zaznacz). Zegarek: stuknięcie włącza / wyłącza rutynę |
| Pora rutyny | OPT zrobione, DEL pomiń; brak odpowiedzi przez 30 s = wróci później |

Na zegarku każdy z tych ekranów ma własne przyciski (*Start*, *Pauza*, *−*, *+* ...), a stuknięcie w tytuł cofa.

## Bluetooth (Ustawienia → Bluetooth)

| Cardputer | Co robi |
|---|---|
| ENTER na *Synchronizuj teraz* | synchronizuj każde urządzenie |
| ENTER na *Dodaj urządzenie* | szukaj urządzeń; ENTER dodaje zaznaczone (wpisz kod, który pokazuje zegarek, potem ENTER) |
| ENTER na urządzeniu | synchronizuj tylko to jedno; **dwa razy DEL** je zapomina |
| ENTER na *Auto-synchronizacja* | zmień okres: na żądanie / co 15, 30, 60, 120, 240 min |
| ESC w trakcie | przerwij |

Zegarek: *Ustawienia → Bluetooth* czeka na Cardputera 2 minuty; przesunięcie w dół na zegarze robi to samo i samo
wraca.

## Ustawienia

- **Personalizacja:** grupy → ustawienia → jedno ustawienie. UP / DOWN przesuwają, ENTER otwiera, ESC cofa; **DEL**
  na ustawieniu przywraca wartość domyślną. Wybory (wł. / wył., kolory, opcje) wybiera się z listy. Liczby i tekst się
  wpisuje: FN + LEFT / RIGHT przesuwają kursor, FN + UP / DOWN zmieniają liczbę o jej krok. ENTER zatwierdza, ESC
  anuluje. Zegarek: stuknięcie włącza / wyłącza, liczby mają przyciski + / −, długie przytrzymanie przywraca wartość
  domyślną.
- **Tryb cichy:** godziny i dni, w których dźwięk / brzęczyk / dioda milczą.
- **Ustaw czas:** LEFT / RIGHT pole, UP / DOWN zmiana, ENTER zapis.
