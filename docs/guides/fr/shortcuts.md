# Raccourcis et navigation

*[English](../en/shortcuts.md) · [Polski](../pl/shortcuts.md) · Français · [Deutsch](../de/shortcuts.md)*

Comment se déplacer dans Squirrel! avec les touches du Cardputer et l'écran tactile de la montre. Version 2.0.

## Partout

| Cardputer | Montre | Ce que ça fait |
|---|---|---|
| UP / DOWN | glisser vers le haut / le bas | se déplacer dans une liste, faire défiler un texte |
| ENTER (ou RIGHT) | toucher | ouvrir, choisir, confirmer |
| ESC (ou LEFT) | glisser vers la droite, toucher le titre, le bouton latéral | retour |
| G0 | — | dictaphone rapide : depuis l'horloge et les menus il démarre aussitôt ; G0 à nouveau enregistre |
| trois fois DEL | — | supprimer la note, la tâche ou l'enregistrement à l'écran (le premier DEL avertit ; ESC annule) |

**DEL**, c'est FN + Backspace. **CTRL, OPT, Aa, ALT, FN** sont des touches à part sur l'horloge ; ailleurs elles
servent de modificateurs (Aa = majuscules, ALT + une lettre = une lettre polonaise / allemande, voir *Personnaliser →
Clavier → Clavier ALT+lettre*).

## L'horloge

| Cardputer | Montre | Ce que ça fait |
|---|---|---|
| toute autre touche | toucher | le menu principal |
| OPT | appui long | lancer / mettre en pause le compteur de concentration |
| **Aa** | **glisser vers le bas** | **synchro rapide** : le Cardputer synchronise chaque appareil Bluetooth et revient ; la montre attend le Cardputer et revient |
| CTRL, puis T | — | une nouvelle tâche (une touche après l'autre) |
| CTRL, puis N | — | une nouvelle note texte |
| **TAB** | — | **le menu TAB** (ci-dessous) |

### Le menu TAB (Cardputer)

Un petit menu par-dessus l'horloge. **TAB** ou UP / DOWN déplacent, ENTER ouvre, ESC ferme ; ou appuie sur la lettre :

| Lettre | Ouvre |
|---|---|
| M | Vide-tête — une pensée rapide, ENTER l'enregistre et tu reviens à l'horloge |
| T | Liste To-Do |
| N | Notes texte |
| V | Notes vocales |
| S | Synchro rapide (comme Aa) |

## Les listes (Liste To-Do, Notes texte, Vide-tête, Notes vocales)

- La première ligne, **+ [Nouveau]**, en crée un.
- **Liste To-Do :** OPT marque la tâche en surbrillance comme faite / pas faite ; une tâche avec des lignes `>` s'ouvre
  comme liste à cocher. Montre : un appui long la marque comme faite.

## Lire et écrire

| Écran | Touches |
|---|---|
| Lecture (une note, une tâche) | UP / DOWN défilent, RIGHT la suivante, ENTER modifier, DEL ×3 supprimer, ESC retour. Montre : les glissements défilent d'une page |
| Liste à cocher | UP / DOWN un élément, OPT cocher / décocher, ENTER modifier la liste, ESC retour. Montre : un toucher coche |
| Éditeur | FN + flèches déplacent le curseur, ENTER une nouvelle ligne, Backspace / DEL effacent, **CTRL+S enregistrer**, ESC abandonner |
| Vide-tête | ENTER enregistre, ESC deux fois abandonne |
| Dictaphone | ENTER ou G0 démarrer / arrêter et enregistrer, ESC abandonne la prise |
| Lecteur | ENTER pause / lecture, LEFT / RIGHT 10 s en arrière / en avant, UP / DOWN volume, DEL ×3 supprimer, ESC arrêter |

## Concentration

| Écran | Touches |
|---|---|
| Pomodoro, Entraînement | ENTER démarrer / pause, DEL arrêter, ESC quitter (le minuteur continue). Entraînement : RIGHT modifie les blocs (UP / DOWN un bloc, LEFT / RIGHT plus court / plus long, ENTER couleur, DEL supprimer, ESC enregistrer) |
| Métronome | LEFT / RIGHT l'intervalle, UP / DOWN le volume, ENTER démarrer / arrêter |
| Respiration | LEFT / RIGHT l'exercice, ENTER démarrer / arrêter |
| Statistiques | ENTER démarrer / mettre en pause le compteur de concentration ; LEFT / RIGHT : cet appareil / chaque appareil synchronisé / ensemble |
| Routines | ENTER ouvrir / nouvelle ; dans une routine ENTER modifie une ligne (heure : LEFT / RIGHT heures ou minutes, UP / DOWN changer ; jours : LEFT / RIGHT un jour, ENTER cocher). Montre : un toucher active / désactive une routine |
| C'est l'heure d'une routine | OPT fait, DEL passer ; pas de réponse pendant 30 s = elle revient plus tard |

Sur la montre, chacun de ces écrans a ses propres boutons (*Démarrer*, *Pause*, *−*, *+* ...), et toucher le titre
ramène en arrière.

## Bluetooth (Réglages → Bluetooth)

| Cardputer | Ce que ça fait |
|---|---|
| ENTER sur *Synchroniser* | synchroniser chaque appareil |
| ENTER sur *Ajouter un appareil* | chercher des appareils ; ENTER ajoute celui en surbrillance (tape le code affiché par la montre, puis ENTER) |
| ENTER sur un appareil | synchroniser seulement celui-là ; **deux fois DEL** l'oublie |
| ENTER sur *Synchro auto* | changer la période : sur demande / toutes les 15, 30, 60, 120, 240 min |
| ESC pendant le travail | arrêter |

Montre : *Réglages → Bluetooth* attend le Cardputer pendant 2 minutes ; glisser vers le bas sur l'horloge fait de même
et revient tout seul.

## Réglages

- **Personnaliser :** groupes → réglages → un réglage. UP / DOWN déplacent, ENTER ouvre, ESC revient ; **DEL** sur un
  réglage remet sa valeur par défaut. Les choix (oui / non, couleurs, options) se prennent dans une liste. Les nombres
  et le texte se tapent : FN + LEFT / RIGHT déplacent le curseur, FN + UP / DOWN changent un nombre de son pas. ENTER
  applique, ESC annule. Montre : un toucher active / désactive, les nombres ont des boutons + / −, un appui long remet
  la valeur par défaut.
- **Mode silencieux :** les heures et les jours où le son / le buzzer / la LED se taisent.
- **Régler l'heure :** LEFT / RIGHT le champ, UP / DOWN le changer, ENTER enregistrer.
