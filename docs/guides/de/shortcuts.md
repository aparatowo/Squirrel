# Tastenkürzel und Navigation

*[English](../en/shortcuts.md) · [Polski](../pl/shortcuts.md) · [Français](../fr/shortcuts.md) · Deutsch*

Wie man sich in Squirrel! mit den Tasten des Cardputers und dem Touchscreen der Uhr bewegt. Version 2.0.

## Überall

| Cardputer | Uhr | Was es tut |
|---|---|---|
| UP / DOWN | nach oben / unten wischen | in einer Liste bewegen, einen Text scrollen |
| ENTER (oder RIGHT) | tippen | öffnen, wählen, bestätigen |
| ESC (oder LEFT) | nach rechts wischen, auf den Titel tippen, die Seitentaste | zurück |
| G0 | — | schneller Sprachrekorder: von der Uhr und aus den Menüs startet er sofort; G0 noch einmal speichert |
| dreimal DEL | — | die Notiz, Aufgabe oder Aufnahme auf dem Bildschirm löschen (das erste DEL warnt; ESC bricht ab) |

**DEL** ist FN + Backspace. **CTRL, OPT, Aa, ALT, FN** sind auf der Uhr eigene Tasten; anderswo wirken sie als
Umschalttasten (Aa = Großbuchstaben, ALT + ein Buchstabe = ein polnischer / deutscher Buchstabe, siehe *Anpassen →
Tastatur → ALT+Buchstabe*).

## Die Uhr

| Cardputer | Uhr | Was es tut |
|---|---|---|
| jede andere Taste | tippen | das Hauptmenü |
| OPT | gedrückt halten | den Fokus-Timer starten / pausieren |
| **Aa** | **nach unten wischen** | **Schnell-Sync**: der Cardputer synchronisiert jedes Bluetooth-Gerät und kommt zurück; die Uhr wartet auf den Cardputer und kommt zurück |
| CTRL, dann T | — | eine neue Aufgabe (eine Taste nach der anderen) |
| CTRL, dann N | — | eine neue Textnotiz |
| **TAB** | — | **das TAB-Menü** (unten) |

### Das TAB-Menü (Cardputer)

Ein kleines Menü über der Uhr. **TAB** oder UP / DOWN bewegen, ENTER öffnet, ESC schließt; oder drück den Buchstaben:

| Buchstabe | Öffnet |
|---|---|
| M | Gedankenablage — ein schneller Gedanke, ENTER speichert ihn und du bist zurück an der Uhr |
| T | To-Do-Liste |
| N | Textnotizen |
| V | Sprachnotizen |
| S | Schnell-Sync (wie Aa) |

## Listen (To-Do-Liste, Textnotizen, Gedankenablage, Sprachnotizen)

- Die erste Zeile, **+ [Neu]**, legt einen Eintrag an.
- **To-Do-Liste:** OPT markiert die gewählte Aufgabe als erledigt / nicht erledigt; eine Aufgabe mit `>`-Zeilen öffnet
  sich als Checkliste. Uhr: langes Drücken markiert sie als erledigt.

## Lesen und Schreiben

| Bildschirm | Tasten |
|---|---|
| Ansicht (eine Notiz, eine Aufgabe) | UP / DOWN scrollen, RIGHT die nächste, ENTER bearbeiten, DEL ×3 löschen, ESC zurück. Uhr: Wischen scrollt seitenweise |
| Checkliste | UP / DOWN ein Punkt, OPT abhaken / zurücknehmen, ENTER die Liste bearbeiten, ESC zurück. Uhr: Tippen hakt ab |
| Editor | FN + Pfeile bewegen den Cursor, ENTER eine neue Zeile, Backspace / DEL löschen, **CTRL+S speichern**, ESC verwerfen |
| Gedankenablage | ENTER speichert, zweimal ESC verwirft |
| Rekorder | ENTER oder G0 Start / Stopp und speichern, ESC verwirft die Aufnahme |
| Player | ENTER Pause / Wiedergabe, LEFT / RIGHT 10 s zurück / vor, UP / DOWN Lautstärke, DEL ×3 löschen, ESC Stopp |

## Fokus

| Bildschirm | Tasten |
|---|---|
| Pomodoro, Training | ENTER Start / Pause, DEL Stopp, ESC verlassen (der Timer läuft weiter). Training: RIGHT bearbeitet die Blöcke (UP / DOWN ein Block, LEFT / RIGHT kürzer / länger, ENTER Farbe, DEL entfernen, ESC speichern) |
| Metronom | LEFT / RIGHT das Intervall, UP / DOWN Lautstärke, ENTER Start / Stopp |
| Atmung | LEFT / RIGHT die Übung, ENTER Start / Stopp |
| Statistik | ENTER den Fokus-Timer starten / pausieren; LEFT / RIGHT: dieses Gerät / jedes synchronisierte / zusammen |
| Routinen | ENTER öffnen / neu; in einer Routine bearbeitet ENTER eine Zeile (Zeit: LEFT / RIGHT Stunde oder Minuten, UP / DOWN ändern; Tage: LEFT / RIGHT ein Tag, ENTER anhaken). Uhr: Tippen schaltet eine Routine ein / aus |
| Eine Routine ist fällig | OPT erledigt, DEL überspringen; 30 s keine Antwort = sie kommt später wieder |

Auf der Uhr hat jeder dieser Bildschirme eigene Knöpfe (*Start*, *Pause*, *−*, *+* ...), und Tippen auf den Titel
geht zurück.

## Bluetooth (Einstellungen → Bluetooth)

| Cardputer | Was es tut |
|---|---|
| ENTER auf *Jetzt synchronisieren* | jedes Gerät synchronisieren |
| ENTER auf *Gerät hinzufügen* | nach Geräten suchen; ENTER fügt das gewählte hinzu (den Code eingeben, den die Uhr zeigt, dann ENTER) |
| ENTER auf einem Gerät | nur dieses synchronisieren; **zweimal DEL** vergisst es |
| ENTER auf *Auto-Sync* | den Abstand wechseln: auf Abruf / alle 15, 30, 60, 120, 240 min |
| ESC während der Arbeit | abbrechen |

Uhr: *Einstellungen → Bluetooth* wartet 2 Minuten auf den Cardputer; nach unten wischen auf der Uhr tut dasselbe und
kehrt von selbst zurück.

## Einstellungen

- **Anpassen:** Gruppen → Einstellungen → eine Einstellung. UP / DOWN bewegen, ENTER öffnet, ESC zurück; **DEL** auf
  einer Einstellung stellt ihren Standardwert wieder her. Auswahlen (an / aus, Farben, Optionen) wählt man aus einer
  Liste. Zahlen und Text tippt man: FN + LEFT / RIGHT bewegen den Cursor, FN + UP / DOWN ändern eine Zahl um ihren
  Schritt. ENTER übernimmt, ESC bricht ab. Uhr: Tippen schaltet an / aus, Zahlen haben + / −-Knöpfe, langes Drücken
  stellt den Standard wieder her.
- **Ruhemodus:** die Stunden und Tage, an denen Ton / Summer / LED schweigen.
- **Zeit stellen:** LEFT / RIGHT das Feld, UP / DOWN ändern, ENTER speichern.
